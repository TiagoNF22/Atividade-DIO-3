# Atividade-DIO-3
# 📊 Dashboard de Vendas - Análise de Desempenho e Visualização de Dados

Este repositório contém o projeto prático desenvolvido no Microsoft Excel com o objetivo de transformar dados brutos de vendas em informações visuais, claras e estratégicas, permitindo uma análise eficaz do desempenho comercial e auxiliando na tomada de decisões baseadas em dados.

---

## 🎯 Sobre o Desafio
O desafio consistiu na construção de um **Dashboard de Vendas** interativo e dinâmico. A proposta central é aplicar técnicas avançadas de organização, tratamento e visualização de dados utilizando o Excel, criando relatórios gerenciais intuitivos (com temática voltada para o universo Xbox / produtos de entretenimento e tecnologia).

## 🚀 O que a ferramenta entrega
* **Visão Geral de Vendas:** Métricas consolidadas de faturamento, quantidade de itens vendidos e ticket médio.
* **Análise Temporal e Categoria:** Indicadores de desempenho divididos por períodos, regiões ou linhas de produtos.
* **Visualização Dinâmica:** Gráficos analíticos integrados para acompanhamento rápido de KPIs essenciais de negócio.
* **Interface Profissional:** Layout limpo e estruturado em formato de painel executivo (dashboard), facilitando a leitura por qualquer usuário sem necessidade de conhecimento prévio em fórmulas complexas.

---

## 🗂️ Estrutura do Repositório

* `base.xlsx` (ou arquivo de dados correspondente): Contém a base de dados brutos utilizada para a alimentação dos modelos e tabelas dinâmicas.
* `dashboard_xbox_finalizado.xlsx` (ou arquivo da solução): A planilha contendo o dashboard concluído, fórmulas, tabelas auxiliares e gráficos interativos.
* `README.md`: Documentação detalhada do projeto.

---

## 🛠️ Tecnologias e Recursos Utilizados
* **Microsoft Excel:** Ferramenta principal para modelagem, estruturação de tabelas e construção do dashboard.
* **Tabelas Dinâmicas / Fórmulas de Agregação:** Para cruzamento e resumo eficiente do volume de dados.
* **Design de Dashboards:** Organização visual em blocos lógicos, uso de cartões de KPIs (Cards) e gráficos adaptados para apresentação executiva.

---

## 💡 Como Reproduzir / Utilizar
1. Faça o download do arquivo Excel finalizado disponível neste repositório.
2. Abra o arquivo no Microsoft Excel.
3. Navegue pelas abas para explorar a base de dados tratada e interaja com os filtros e gráficos do dashboard para analisar os cenários de vendas.
